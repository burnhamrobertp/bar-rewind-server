Workers

Machines that parse queued replays. To add one, download the worker from its latest release and run it: it opens this site to be approved. If Windows warns that it protected your PC: More info > Run anyway.

Workers move to the pinned releases at their next heartbeat; one on another parser gets no jobs until it has. An empty field unpins it. Parses older than the .curves version show as outdated.
