The player

Watch on a parsed replay opens it in your own BAR install, through the BAR Rewind player. Set it up once: after that, Watch starts BAR on the replay, with the timeline to scrub, rewind and change speed.

Needs BAR installed. The player adds the BAR Rewind game to BAR's data folder (games/barrewind.sdd), downloads a replay's engine, game and map with BAR's own downloader when they're missing, then starts BAR. It changes nothing else in BAR.

Windows On Linux?

Download bar-rewind.exe

  1. Your browser may hold the download back because few people download this file. Keep it: in Chrome or Edge open the downloads list, then ... > Keep (Edge: Keep anyway).
  2. Move it somewhere it can stay, for example Documents\BAR Rewind. Watch links open the copy you ran last.
  3. Double-click it. Windows may say Windows protected your PC, because the player isn't signed: More info > Run anyway.
  4. A window confirms it's set up and shows the BAR data folder it found. Press Enter to close it.
  5. Click Watch on a parsed replay. The first time, the browser asks to open BAR Rewind: allow it (and tick "always allow" to skip the question next time).
  6. The player then asks whether to trust downloads from this site. Type y and Enter; it remembers, and won't ask again for this site.

To remove it: run bar-rewind.exe --uninstall from a terminal, then delete the file.

Linux On Windows?

Download bar-rewind

  1. Move it somewhere it can stay and make it runnable: mkdir -p ~/.local/bin && mv ~/Downloads/bar-rewind ~/.local/bin/ && chmod +x ~/.local/bin/bar-rewind
  2. Run it once in a terminal: ~/.local/bin/bar-rewind. It registers itself for your user (a desktop entry in ~/.local/share/applications); it needs xdg-utils, which most desktops have.
  3. Click Watch on a parsed replay. The player opens in a terminal window, so downloads and errors show there. The first time, it asks whether to trust downloads from this site: type y and Enter.

To remove it: ~/.local/bin/bar-rewind --uninstall, then delete the file.

Widgets

Widgets for BAR Rewind playback. Save them into LuaUI/Widgets in BAR's data folder (the folder the player found), then start a replay; turn them on or off in BAR's widget list (F11).

    If BAR isn't found

    The player looks where BAR's installers put its data folder (the one with engine/, maps/ and demos/ in it). For anywhere else, put {"bar_data": "<BAR's data folder>"} in %APPDATA%\bar-rewind.json (Windows) or ~/.config/bar-rewind.json (Linux). The same file lists the sites you trusted (trusted_hosts); remove one there to be asked again. Downloaded replays and BAR's log from the last Watch are in %LOCALAPPDATA%\bar-rewind or ~/.cache/bar-rewind.
