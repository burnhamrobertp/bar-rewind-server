Player for watching replays

Opens a parsed replay in your own BAR with a timeline. Set it up once; after that, Watch on the Replays page does the rest. Needs BAR installed.

Showing Windows steps. Show the Linux steps

Download bar-rewind.exe

  1. Keep it somewhere it can stay. If the browser holds the download back, choose Keep.
  2. Run it once. If Windows warns that it protected your PC: More info > Run anyway.
  3. Click Watch on a replay, let the browser open BAR Rewind, and type y when the player asks to trust this site.

BAR not found? Put {"bar_data": "<BAR's data folder>"} in %APPDATA%\bar-rewind.json.

To remove it: bar-rewind.exe --uninstall, then delete the file.

Download bar-rewind

  1. Install and register it (needs xdg-utils): mkdir -p ~/.local/bin && mv ~/Downloads/bar-rewind-player-linux ~/.local/bin/bar-rewind && chmod +x ~/.local/bin/bar-rewind && ~/.local/bin/bar-rewind
  2. Click Watch on a replay, and type y when the player asks to trust this site.

BAR not found? Put {"bar_data": "<BAR's data folder>"} in ~/.config/bar-rewind.json.

To remove it: ~/.local/bin/bar-rewind --uninstall, then delete the file.
