Worker for lending your machine

Parses queued replays for this site in the background. Only run it on a machine you're happy to share; you can pause or remove it any time on the Workers page.

Needs BAR installed. It takes no job while BAR is running, or while less than 4 GB of memory or 10 GB of disk is free. No admin rights needed.

Showing Windows steps. Show the Linux steps

Download bar-rewind-worker.exe

  1. In the folder you downloaded it to, type cmd in the address bar and press Enter, then run bar-rewind-worker.exe install. If Windows warns that it protected your PC: More info > Run anyway.
  2. It opens this site with a code: check it matches, then approve. From then on it starts when you sign in to Windows.

To remove it: bar-rewind-worker.exe uninstall. Its files are in %LOCALAPPDATA%\bar-rewind-worker.

Download bar-rewind-worker

  1. Install it: chmod +x ~/Downloads/bar-rewind-worker-linux && ~/Downloads/bar-rewind-worker-linux install
  2. It opens this site with a code: check it matches, then approve. From then on it runs as a systemd user service.

To remove it: bar-rewind-worker-linux uninstall. Its files are in ~/.local/share/bar-rewind-worker.
